# Magnólia

Karbonlábnyom-követő cross-platform alkalmazás, Ionic Angular és Firebase alapokon.

A kitelepített weboldal elérhető a https://magnolia-def2f.web.app linken.

## Futtatás

```bash
npm install
ionic serve
```

## Build és telepítés

```bash
npm run buildweb       # Webes build
npm run deployweb      # Firebase Hosting deploy
npm run ios            # iOS build + Xcode megnyitása
npm run android        # Android build + Android Studio megnyitása
```
